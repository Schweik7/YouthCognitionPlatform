# 学习力测评平台设计规范

> 一套面向儿童认知能力测评的界面语言：温和克制的视觉、绝不干扰题目的排版，
> 以及一份到处都一样的数据表结构。本文档把它拆成可以直接搬走的令牌与规则。

| 项 | 值 |
| --- | --- |
| 技术栈 | Vue 3 + Element Plus + FastAPI |
| 令牌载体 | `src/styles/design-system.css` |
| 主题版本 | 5 套 |
| 在线版 | https://claude.ai/code/artifact/972a79bf-db52-447d-89e4-e02e6b65562c （含可切换主题的组件预览） |

## 01 设计原则

五条约束，任何一次改版都不越过它们。它们解释了后面每一个取值为什么长这样。

**题目材料神圣不可侵犯**
视觉系统只作用于外壳：背景、卡片、按钮、间距。测验的文字、字号、呈现顺序、刺激材料的字体（楷体）与尺寸由心理测量学决定，不接受任何"美化"。改版时先问一句：这行代码碰到题目了吗？

**安静优先于活泼**
用户是正在被测量的孩子。界面要友好，但不能抢注意力：没有跳动的动画、没有大面积高饱和色块、没有装饰性插画进入答题区。品牌色只出现在操作元素上。

**一屏一件事**
封面只做登录，选择页只做选择，测评页只有题目和一个继续按钮。任何"顺便放个说明"的冲动都要被砍掉——那是主试口头讲的内容。

**数字必须稳定**
计时器、得分、进度全部使用表格数字（`tabular-nums`），宽度不随数值变化。数字跳动会被孩子当成反馈信号。

**数据结构先于界面**
所有测验的结果表共用「用户信息 / 测试信息 / 任务指标信息」三段结构，由后端下发列定义、前端照单渲染。加一个测验，不需要改一行表格代码。

## 02 色彩与主题版本

色彩分四层：**品牌色**（唯一强调，只给可操作元素）、**模块辅助色**（区分六个测验，不承担强调）、**功能色**（对错与状态，跨主题固定不变）、**中性色**（承担 90% 的画面）。

### 主题版本

五套都按同一结构给出 600/500/400/100/50 五档。品牌色换掉后，中性色与功能色保持原样即可成立——这是把系统搬到别的项目上最省力的一条路。

| 版本 | 适用场景 | brand-600 | brand-500 | brand-400 | brand-100 | brand-50 | 建议中性偏色 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 靛蓝 Indigo | 通用学业测评，现平台在用 | `#3a56d4` | `#4c6fff` | `#7d95ff` | `#e4eaff` | `#f1f4ff` | 冷灰偏蓝 `#131a2b` |
| 青松 Pine | 体检、筛查、健康类项目 | `#0b7d72` | `#12a89b` | `#4ec7bb` | `#d6f2ee` | `#eefaf8` | 灰绿 `#10231f` |
| 陶土 Clay | 幼儿园至小学低年级，需要暖意 | `#c14a24` | `#e2643a` | `#f0906d` | `#fbe3d9` | `#fdf3ee` | 暖褐灰 `#241813` |
| 紫棠 Plum | 科研版、实验室数据采集 | `#5b3bc4` | `#7857f0` | `#a48bf7` | `#e8e1fd` | `#f5f2fe` | 紫灰 `#1b1630` |
| 墨蓝 Ink | 教育局、学校管理端，去童趣 | `#1f3556` | `#2f4f7d` | `#6d88ae` | `#dce4ef` | `#eff3f8` | 石板灰 `#141b26` |

五档的职责：600 深（主按钮渐变末端、强调文字）、500 主（按钮底、聚焦环、链接）、400 浅（渐变起点、hover）、100 淡（标签底）、50 极淡（聚焦光晕、眉标签底）。

### 模块辅助色

六个测验各一个色相，用于选择页的卡片图标、进度标识、结果图表分组。它们**不用作按钮底色**——一旦用作操作色，孩子会以为不同测验的按钮功能不同。

| 模块 | 变量 | 色值 |
| --- | --- | --- |
| 阅读流畅性 | `--hue-reading` | `#4c6fff` |
| 朗读流畅性 | `--hue-oral` | `#f0743a` |
| 注意力筛查 | `--hue-attention` | `#12b3a8` |
| 计算流畅性 | `--hue-calc` | `#8b5cf6` |
| 识字量 | `--hue-literacy` | `#e0518c` |
| 图形推理 | `--hue-raven` | `#f0a92c` |

### 功能色

跨主题固定：换品牌色时不要跟着调，否则"正确"的绿会在不同项目里表示不同含义。每个功能色配一个 soft 底色，用于标签与提示块。

| 语义 | 主色 | soft 底色 |
| --- | --- | --- |
| 成功 / 正确 | `#17b26a` | `#e6f7ef` |
| 警告 / 剩余时间 | `#f5a524` | `#fef4e2` |
| 错误 / 遗漏 | `#f04438` | `#feecea` |
| 信息 | `#4c6fff` | `#eef2ff` |

### 中性色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink-900` | `#131a2b` | 标题 |
| `--ink-700` | `#2c3752` | 正文 |
| `--ink-500` | `#5a6784` | 次要文字、表头 |
| `--ink-400` | `#7e8aa3` | 占位、辅助说明 |
| `--ink-300` | `#a6b0c3` | 禁用文字 |
| `--line` | `#e6eaf3` | 描边 |
| `--line-soft` | `#eff2f8` | 内部分隔线 |
| `--surface` | `#ffffff` | 卡片底 |
| `--surface-alt` | `#f8fafd` | 表头、次级底 |
| `--canvas` | `#f4f6fb` | 页面画布 |

> **中性色不是纯灰。** 全部向品牌色相偏一点（靛蓝主题下带蓝），这样文字压在卡片上时是"同一套光线"下的关系。换主题时，中性色也顺着新品牌色微调色相，饱和度控制在 6% 以内。

## 03 字体与字阶

三个字族角色各司其职，混用是最常见的走样来源。

| 角色 | 变量 | 字族 | 用在哪 |
| --- | --- | --- | --- |
| 界面字 | `--font-ui` | PingFang SC → HarmonyOS Sans SC → Microsoft YaHei → 系统无衬线 | 全站默认，标题正文按钮标签 |
| 数字字 | `--font-num` | DIN Alternate → SF Pro Display → Helvetica Neue | 计时、得分、统计数值，必须配 `tabular-nums` |
| 刺激字 | `--font-stim` | Kaiti SC → KaiTi → STKaiti（楷体） | **仅**测验题目中的汉字刺激，符合小学课本字形 |

### 字阶

| 层级 | 字号 | 字重 | 行高 | 字距 |
| --- | --- | --- | --- | --- |
| 品牌名（顶栏） | `clamp(20px, 2.1vw, 30px)` | 800 | 1.2 | -.01em，`white-space: nowrap` |
| 页面主标题 | 24–28px | 700 | 1.4 | -.01em |
| 卡片标题 | 16–18px | 700 | 1.5 | 0 |
| 正文 / 表单标签 | 14–15px | 400 / 600 | 1.7 | +.01em |
| 辅助说明 | 13px | 400 | 1.6 | +.01em |
| 眉标签 eyebrow | 12px | 700 | 1.4 | +.08em |
| 计时 / 数值 | 18–28px | 700 | 1 | 表格数字 |

> **顶栏平台名必须一行不断。** 中文长名在 100% 缩放下最容易折行，用 `clamp()` 收字号 + `white-space: nowrap` 锁住，而不是靠缩小容器。这条是踩过坑写下来的。

## 04 圆角・阴影・间距

圆角越大的元素层级越高：输入框最小，卡片中等，主容器最大。阴影只有"浮起"一种语义，不用来画边框。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--r-xs` | 8px | 标签、小图标底 |
| `--r-sm` | 12px | 输入框、大号按钮 |
| `--r-md` | 16px | 内层小卡片 |
| `--r-lg` | 22px | 主卡片、对话框 |
| `--r-xl` | 30px | 登录面板等主容器 |
| `--r-full` | 999px | 药丸按钮、标签、进度条 |
| `--sh-xs` | `0 1px 2px rgba(19,26,43,.05)` | 极轻浮起 |
| `--sh-sm` | `0 2px 8px rgba(19,26,43,.06)` | 静态卡片 |
| `--sh-md` | `0 8px 24px rgba(19,26,43,.08)` | 对话框、悬浮层 |
| `--sh-lg` | `0 18px 46px rgba(19,26,43,.10)` | 主视觉面板 |
| `--sh-brand` | `0 10px 26px rgba(76,111,255,.26)` | 主按钮，随品牌色改 |

间距用 8 的倍数为主，一共八档：`4 · 8 · 12 · 16 · 24 · 32 · 44 · 64`。兄弟元素之间一律用 flex/grid 的 `gap`，不用 margin 拼——外边距塌陷是这套系统里最常见的错位来源。

## 05 Logo 与品牌条

标识是一个 32×32 视窗的内联 SVG：圆角方块渐变底 + 白色 "m" 形笔画 + 下方圆点，象征"两条学习曲线与一个落点"。它是代码而不是图片，因此能跟着主题色一起换。

```html
<svg viewBox="0 0 32 32" aria-hidden="true">
  <rect x="2" y="2" width="28" height="28" rx="9" fill="url(#bm)" />
  <path d="M10 21V13.5c0-1.7 1.4-3 3.1-3 1.3 0 2.4.8 2.9 2 .5-1.2 1.6-2 2.9-2 1.7 0 3.1 1.3 3.1 3V21"
        fill="none" stroke="#fff" stroke-width="2.4" stroke-linecap="round" />
  <circle cx="16" cy="24.5" r="1.7" fill="#fff" />
  <defs>
    <linearGradient id="bm" x1="0" y1="0" x2="1" y2="1">
      <stop offset="0%" stop-color="var(--brand-400)" />
      <stop offset="100%" stop-color="var(--brand-600)" />
    </linearGradient>
  </defs>
</svg>
```

- **标识尺寸**：顶栏 46px，测评页内 32px，favicon 32px。低于 28px 时去掉下方圆点。
- **标识与文字间距**：14px，固定值不随字号变。
- **唯一性**：平台名**只在顶栏出现一次**。封面主视觉下方不再重复标题——重复的品牌名是廉价感的第一来源。
- **顶栏结构**：左侧标识 + 平台名，右侧功能入口（后台登录 / 返回首页 / 退出），中间留空。`justify-content: space-between`，纵向内边距 22px，横向 `clamp(20px, 5vw, 56px)`。
- **渐变方向**：所有品牌渐变统一 135°，由 400 档到 600 档。

## 06 按钮

一屏最多一个主按钮。测评页里的主按钮永远是"继续/提交"，位置固定在右下，让孩子在整个测验流程中形成肌肉记忆。

| 类型 | 外观 | 圆角 | 内边距 | 用途 |
| --- | --- | --- | --- | --- |
| 主按钮 | 135° 品牌渐变 + 品牌阴影，白字 | 12px | 14px 26px | 每屏唯一的推进动作 |
| 次按钮 | 白底 + 1px 描边，深色字 | 10px | 11px 20px | 返回、上一题 |
| 药丸按钮 | 白底 + 品牌色描边与文字 | 999px | 10px 18px | 顶栏入口，弱化但可发现 |
| 文字按钮 | 无底无框，品牌色文字 | — | 13px 10px | 表单内的次要跳转 |

- **交互**：hover 上移 1px + 提亮一档；active 归位；过渡 `.18s ease`，只动 transform / box-shadow / background。
- **禁用**：`opacity: .55`，去掉位移与阴影。禁用时按钮文案要说明原因（"请等待录音结束"），而不是保持原文案。
- **键盘焦点**：`outline: 2px solid 品牌色; outline-offset: 3px`，绝不用 `outline: none` 收场。
- **尺寸**：测评流程内一律 large（16px 字，48px 高），后台管理内用 small——两种场景的操作密度完全不同。

## 07 表单与容器

### 输入控件

- 标签置顶（`label-position="top"`），字重 600——中文标签左置会让每行的输入起点参差不齐。
- 边框用 `inset box-shadow` 而非 border，聚焦时叠一圈 4px 品牌淡色光晕，尺寸不跳。
- 两个短字段（学号+姓名、年级+班级）并成一行 `grid-template-columns: 1fr 1fr`，长字段独占一行。
- 回车即提交：每个输入框绑 `@keyup.enter`，主试常常用键盘不用鼠标。

### 卡片与对话框

- **卡片**：白底 + 1px `--line` 描边 + `--sh-sm`，圆角 22px，内边距 24px，头部 20px/24px 且带 1px 分隔线。
- **对话框**：圆角 22px、`overflow: hidden`、标题 700 字重；登录类窄框 380px，数据类宽框 920px 且 `top: 5vh`。
- **表格**：表头底色 `--surface-alt`、文字 `--ink-500`、字重 600；单元格分隔线用最浅的 `--line-soft`。
- **消息提示**：全圆角药丸 + `--sh-md`，无描边。错误提示要写清怎么办（"学号与姓名不匹配，或该学号尚未登记"）。

## 08 页面布局骨架

三类页面，三种骨架。共用一个背景：画布色 + 左上品牌色、右上辅助色两团大半径径向渐变，透明度都在 10% 以内——有空气感但不构成图形。

```css
.page-shell {
  min-height: 100vh;
  background:
    radial-gradient(1100px 520px at 12% -8%, rgba(76, 111, 255, .10), transparent 62%),
    radial-gradient(900px 480px at 96% 4%, rgba(18, 179, 168, .09), transparent 60%),
    var(--canvas);
}
```

| 骨架类 | 最大宽度 | 内容策略 |
| --- | --- | --- |
| `.page-wrap--narrow` | 880px | 表单、说明、结果页 |
| `.page-wrap` | 1120px | 测评页默认 |
| `.page-wrap--wide` | 1320px | 后台数据表 |

**封面页** · 双栏 `minmax(0, 1.1fr) / minmax(360px, 440px)`，容器 1280px
顶栏（标识 + 平台名 ／ 后台登录）＋ 左主视觉插画（`max-width: min(560px, 100%)`）＋ 右登录面板（圆角 30px）。

**测评页** · 单栏居中 1120px
顶栏（标识 + 测验名 ／ 计时药丸）＋ 题目区（唯一的视觉重心）＋ 底部进度条与继续按钮。

**后台页** · 单卡通栏 1320px
标题行（管理员名 ／ 返回首页 ／ 退出登录）＋ 筛选行 ＋ 导出行 ＋ 测验类型标签页 ＋ 分组表头数据表。

> **断点只有两个：900px 与 768px。** 900px 以下双栏拆单栏，768px 以下选项网格由 3 列降到 2 列。测评设备基本是教室里的笔记本或平板，不为手机端做第三套排版。

## 09 测评页专用件

这几个组件是测评类产品和普通后台产品的真正分野。

### 计时药丸

常态用成功色淡底（`#e6f7ef` / `#0f8f56`），进入最后 30 秒切到警告淡底并以 1.4s 呼吸式透明度提示。**不用红色、不做缩放抖动**——那会直接影响作答表现。数字字族 + 表格数字，宽度恒定。

### 题目区双栏

图形类题目（如瑞文推理）左图右选项：

```css
.question-area {
  flex: 1; min-height: 0;                 /* 让图片拿到剩余高度 */
  display: grid;
  grid-template-columns: minmax(0, 1.2fr) minmax(300px, .8fr);
  align-items: center;
  gap: clamp(14px, 2vw, 26px);
}
.main-image { max-width: 100%; max-height: 100%; object-fit: contain; }
.options-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); gap: 10px; }
.option-item { aspect-ratio: 1; max-width: 168px; width: 100%; }
```

关键三点：容器 `flex: 1; min-height: 0` 让图片拿到剩余高度；图片 `max-height: 100%; object-fit: contain` 保证完整显示；选项统一 3 列、单元格 `aspect-ratio: 1` 且 `max-width: 168px`，避免 8 选项时把主图挤没。

### 眉标签与进度

流程位置用眉标签表达（`STEP 2`），进度用全圆角进度条，两者都放在题目区外侧。进度条不显示百分比数字——那会诱发赶工。

### 选择页卡片

六个测验各一张卡片，卡片只用模块辅助色做图标底与顶部细色条，标题 + 一句话说明 + 状态标签（未开始/已完成）。已完成的卡片降到 `opacity: .7` 并保留可重测入口。

## 10 后台与数据规范

这一节是整套系统最容易被低估、也最值得照抄的部分：把表格结构定义在后端，前端只负责渲染，新增测验时界面零改动。

### 三段式列结构

| 分组 | 字段 | 来源 |
| --- | --- | --- |
| 用户信息 | 姓名 · 学号 · 学校 · 年级 · 班级 · 出生日期 | 用户档案，登记时一次性录入 |
| 测试信息 | 测验序号 · 登录时间 · 测试时间 · 结束时间 · 状态 | 本次会话，登录与答题过程自动写入 |
| 任务指标信息 | 各测验自定义（正确数 / 用时 / 字每分 / 得分…） | 测验会话表的汇总字段 |
| 任务明细信息 | 逐题作答记录，列名统一加"明细·"前缀 | 仅导出宽表时展开 |

接口同时下发扁平 `columns` 与分组 `column_groups`：前者保证导出列序，后者驱动分组表头。

```python
# 后端：一处定义，所有测验共用
_USER_COLUMNS = ["姓名", "学号", "学校", "年级", "班级", "出生日期"]
_TEST_COLUMNS = ["测验序号", "登录时间", "测试时间", "结束时间", "状态"]

# 每个测验只需登记自己的指标字段
TEST_REGISTRY = {
    "reading_fluency": {
        "label": "阅读流畅性",
        "metrics": [("correct_count", "正确数"), ("total_time_seconds", "用时(秒)")],
    },
}
```

```html
<!-- 前端：照单渲染，新增测验不用改这里 -->
<el-table-column v-for="group in tests[key].column_groups" :label="group.label" align="center">
  <el-table-column v-for="col in group.columns" :prop="col" :label="col" min-width="110" />
</el-table-column>
```

### 字段命名约定

- 列名用**中文**直出，因为最终读者是教师和研究者，导出的 Excel 不应该再做一次映射。
- 带单位的字段把单位写进列名：`用时(秒)`、`平均(字/分)`。
- 时间统一 `YYYY-MM-DD HH:MM:SS`；空值导出为空字符串而不是 `None` / `NaN`。
- 内部字段用 `__test_id__` 双下划线包裹，前端用于勾选与查看明细，永不作为表格列出现。
- CSV 一律 `utf-8-sig`（带 BOM），否则中文在 Excel 里是乱码。

### 登录与身份采集

- **首次登记**收全量信息并绑定学号；**快速登录**只要学号 + 姓名，避免重复测量时反复录入。
- **测验序号**在登录时填（第几次测验），这是前后测比对的关键字段，放在登记表单里就取不到了。
- **登录时间自动写入**，不依赖人工填写。记录失败只写日志、不阻断孩子开始测验——采集流程永远不能被辅助功能卡住。
- 同名同校同班的历史用户在登记时直接绑定学号，而不是新建档案，防止成绩被切成两半。

### 管理员鉴权

- 账号密码登录换取 HMAC 签名令牌（12 小时有效），后台除登录外**所有**接口校验。
- 令牌同时接受 `Authorization: Bearer` 与 `?token=` 查询参数——导出下载与音频播放是浏览器直接开链接，带不了自定义请求头。
- 账号密码**不进仓库**：代码里只留占位默认值，真实值走环境变量（部署机放 `/etc/eduscreen/backend.env`，权限 600）。
- 前端拿到 401 就清除本地令牌并退回封面页，不在后台页里做二次登录框。

> **数据库演进用幂等补列。** `create_all` 不会修改已有表，启动时用 `inspect()` 比对再 `ALTER TABLE ADD COLUMN`，只增不减。线上有真实被试数据时，这是唯一安全的加字段方式。

## 11 复刻清单

把这套系统搬到新项目，按顺序做完这十一步即可。

1. 复制 `design-system.css`，只改品牌色五档与中性色的色相偏移，其余令牌不动。
2. 在 `main.js` 里于组件库样式**之后**引入它，确保 Element Plus 变量映射生效。
3. 从五套主题里挑一套，或按"品牌色 + 中性色微偏色相"的规则自制一套。
4. 把标识改成自己的内联 SVG，渐变端点接品牌变量，保持 32 视窗与 135° 方向。
5. 顶栏落地：左标识 + 名称（`clamp` + `nowrap`），右功能入口。
6. 按三档 `page-wrap` 定页面宽度，背景统一用双径向渐变。
7. 表单一律标签置顶、短字段两列、回车提交。
8. 后端定义 `_USER_COLUMNS` / `_TEST_COLUMNS` 与各任务的 metrics 注册表。
9. 接口同时返回 `columns` 与 `column_groups`，前端只渲染不硬编码。
10. 管理端接令牌鉴权，密码走环境变量，导出链接用查询参数带令牌。
11. 上线前逐条自查：题目材料没被改动、数字用了表格数字、焦点样式可见、`prefers-reduced-motion` 已尊重。
